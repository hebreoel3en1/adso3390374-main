## 📌 Descripción del Proyecto

Este repositorio contiene el portafolio de evidencias y prácticas desarrolladas durante la formación tecnológica en **Análisis y Desarrollo de Software (ADSO)** en el SENA. Incluye ejercicios prácticos, retos de maquetación, uso de etiquetas semánticas, hojas de estilo en cascada (CSS3), responsive design y futuros módulos de programación web.
